台灣第一家鹽酥雞 APP（PWA 安裝版）

【上傳位置】把 app.html、manifest.webmanifest、service-worker.js、icons 整個資料夾上傳到 GitHub Pages 的 Shop/ 資料夾。
原有頁面請保留：Shop/menu.html（計算機）、Shop/221.html（虛擬夜市）。不要覆蓋 pos.html 或 Pos1.html。

【入口網址】https://smnhg89vrc-cmyk.github.io/Shop/app.html

【iPhone】用 Safari 開啟網址→分享→加入主畫面→新增。
【Android】用 Chrome 開啟網址→按「安裝到手機桌面」或選單中的「安裝應用程式」。

計算機僅供自行估價，並非線上點餐。離線能力為基本快取，菜單同步、付款、遊戲動態內容仍可能需要網路。
正式上架 App Store / Google Play 還需 Capacitor 原生專案、開發者帳號、簽章、測試與商店審核；本包不是已簽章的 IPA/AAB。
